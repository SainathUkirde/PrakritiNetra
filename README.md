# 🌿 PrakritiNetra — Smarter Forecasts | Healthier Tomorrow

**Hybrid AI–NWP Adaptive Forecast Blending System for India**

PrakritiNetra ("Prakriti" = nature, "Netra" = vision) is a production-quality,
end-to-end framework that dynamically blends multiple numerical weather prediction
(NWP), ensemble, and AI/ML forecast sources using adaptive, spatially varying
weights informed by historical skill, lead time, season, and unsupervised
weather-regime classification.

> **Domain:** India (8–37°N, 68–97°E) · **Variables:** Rainfall, Temperature, Wind  
> **Sources:** GFS (NWP) · GEFS (Ensemble) · Pangu-Weather (AI)  
> **Truth / Validation:** ERA5 reanalysis

---

## Features

| # | Feature | Module |
|---|---------|--------|
| 1 | **Sector-Adaptive Blending** — re-weights the blend per sector (Agriculture / Hydrology / Aviation / Energy) with dynamic explanation | `sector_profiles.py` |
| 2 | **Enhanced Dynamic Weight Map** — interactive hover map showing dominant source, numeric weights, region-type proxy, and uncertainty overlay | `weight_map_enhanced.py` |
| 3 | **Self-Learning Feedback Loop** — incremental skill-table updates as new ERA5 truth arrives; before/after weight-shift demonstration | `feedback_loop.py` |
| 4 | **Forecast Confidence Score** — per-cell model-agreement %, combined confidence %, and expected range | `confidence_score.py` |
| 5 | **Automated Extreme Weather Alerts** — 3-tier severity (WATCH / WARNING / SEVERE), confidence-aware, district-level, sector-specific phrasing | `alerts.py` |
| 6 | **Extreme Weather Indicators panel** — all three hazards (Heavy Rainfall ≥50 mm · Heatwave ≥40 °C · Gales ≥17.2 m/s) shown simultaneously, variable-independent | `app.py` |

## Quick Start

```bash
# 1. Clone
git clone https://github.com/SainathUkirde/PrakritiNetra.git
cd PrakritiNetra

# 2. Install dependencies
pip install -r requirements.txt

# 3. Download real data (needs ECMWF / NOAA credentials)
#    OR skip to step 4 if you already have datasets/ populated
python download_gfs.py
python download_gefs.py
python download_era5.py

# 4. Run the full pipeline  (~35 s on a standard laptop)
python run_pipeline.py

# 5. Launch the interactive dashboard
streamlit run app.py
#    → opens at http://localhost:8501
```

On Windows, double-click **`START_DASHBOARD.bat`** instead of step 5.

## Pipeline Steps (`run_pipeline.py`)

```
STEP 1  Load real data      GFS + GEFS + Pangu-Weather + ERA5
STEP 2  Classify regimes    KMeans or GMM on synoptic features
STEP 3  Score skill         RMSE / MAE / bias per (var, src, lead, region, season, regime)
STEP 4  Build weights       Inverse-error normalised weights per bucket
STEP 5  Blend + flag        Spatially adaptive blend; extreme-weather binary flags
STEP 6  Skill comparison    Blended vs naive vs individual sources
STEP 7  Save outputs        CSVs + classifier.pkl + run_summary.json
```

## Extreme Weather Thresholds

| Hazard | Default threshold | Configurable? |
|--------|------------------|---------------|
| Heavy Rainfall | ≥ 50 mm | ✅ Dashboard slider |
| Heatwave | ≥ 40 °C | ✅ Dashboard slider |
| Gale-force Wind | ≥ 17.2 m/s (Beaufort 8) | ✅ Dashboard slider |

Alert severity is **confidence-aware**: a threshold crossing with low model agreement
is downgraded to WATCH rather than WARNING/SEVERE.

## Data Notes

- **GFS / GEFS:** Downloaded for Sep 16–22, 2026 (7 cycles × 4 lead times: 6 h / 24 h / 72 h / 168 h)
- **ERA5:** Jan 2023 + Sep 2023 (day-of-year proxy match to Sep 2026 forecasts — explicitly labeled as proxy)
- **Pangu-Weather:** Jan 2022 (no date overlap with GFS/GEFS; DOY proxy used — labeled)
- **AI + Rainfall:** Pangu-Weather does not include rainfall predictions. This is handled throughout the system — AI is shown as "N/A" for rainfall, never coerced to zero or NaN.
